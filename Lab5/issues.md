# Lab 5: Documented Issues

Issues are ordered by severity (High first, then Medium, then Low/style).
All line numbers and descriptions are taken from the actual before-fix reports
(`bandit_before.txt`, `pylint_before.txt`, `flake8_before.txt`).

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| B324 — Weak MD5 hash | Security (High) | 31 | `hashlib.md5()` used for SKU checksum. MD5 is cryptographically broken (CWE-327). Bandit flags it as High severity. | Replace `hashlib.md5` with `hashlib.sha256`. No `usedforsecurity=False` workaround needed because the hash is being replaced, not kept. |
| B307 — Use of `eval()` | Security (Medium) | 62, 80 | Two calls to `eval()`: one evaluates a user-supplied stock formula (`eval(formula, {"current": current})`), the other calls `eval("print('stock audit complete')")`. Both allow arbitrary code execution (CWE-78). | Remove both `eval()` calls. Implement `safe_calculate()` using `ast.parse()` in `"eval"` mode, then walk the AST allowing only numeric constants, the name `current`, binary arithmetic ops (`+`, `-`, `*`, `/`), and unary `+`/`-`. Replace the second `eval()` with a plain `print()`. |
| B105 — Hardcoded password | Security (Low) | 10 | `SUPERVISOR_PASSWORD = "wh-admin-1234"` stores a credential directly in source code (CWE-259). Anyone with read access to the file or its Git history can retrieve the password. | Replace with `os.environ.get("WAREHOUSE_SUPERVISOR_PASSWORD")`. In `apply_adjustment`, refuse authentication if the env var is unset or the provided password does not match. |
| B110 — Bare `except: pass` | Security (Low) / Style | 23–24 | `except: pass` inside `remove_stock` silently swallows all exceptions, including `KeyError` when removing a SKU that does not exist. Hides real bugs and prevents proper error reporting (CWE-703). | Remove the bare `except` block. Instead, guard with an explicit `if sku not in warehouse_stock: return` check before the subtraction, so the logic is explicit and no exception needs to be swallowed. |
| C0103 — Non-snake_case names | Code quality (Pylint) | 12, 18, 26, 29, 33, 39, 44, 49, 57 | Eight functions use camelCase: `addStock`, `removeStock`, `getStock`, `skuChecksum`, `loadStock`, `saveStock`, `printReport`, `checkReorder`, `applyAdjustment`. PEP 8 requires `snake_case`. A subsequent rename also caused a `NameError` at runtime because one call site was not updated. | Rename all eight functions to their `snake_case` equivalents and update every call site throughout the file. |
| W0102 — Mutable default argument | Code quality (Pylint) | 12 | `def addStock(sku, qty, history=[])` — the default list `[]` is created once and shared across all calls that use the default. Mutations persist between calls, causing unexpected behaviour. | Change the default to `history=None`. Inside the function body, replace any reference to `history` that assumed a list with `if history is not None: history.append(...)`. |
| C0114 / C0116 — Missing docstrings | Code quality (Pylint) | 1, 12, 18, 26, 29, 33, 39, 44, 49, 57, 67 | No module-level docstring and no docstrings on any of the eight functions. Makes the code unmaintainable. | Add a one-line module docstring. Add a descriptive docstring to every function explaining its purpose, parameters, and return value where applicable. |
| R1732 / E302 / E501 / W291 — Style violations | Style (Pylint / Flake8) | 34, 40, 63, multiple | Three `open()` calls without context managers (resource leaks); eight functions with only one blank line before them (E302 requires two); two lines exceeding 79 characters (E501); one trailing whitespace (W291); one unused local variable `total_units` (F841). | Wrap all `open()` calls in `with` statements and add `encoding='utf-8'`. Add a second blank line before each top-level function definition. Wrap long lines using Python's implicit line continuation inside brackets. Remove the unused variable. |
